# Contributing to VoxSpace

Thank you for your interest in contributing to the **VoxSpace** repository! We welcome contributions from the community to improve the application, add features, or enhance documentation.

## How to Contribute

### 1. Reporting Issues
- Check the [issue tracker](https://github.com/voxdroid/VoxSpace/issues) to ensure the issue hasn't been reported.
- Use the appropriate issue template (bug report, feature request, or documentation improvement) in `.github/ISSUE_TEMPLATE/`.
- Provide clear details, including steps to reproduce, expected behavior, and actual behavior.

### 2. Submitting Pull Requests
- Fork the repository and create a new branch for your changes (`git checkout -b feature/your-feature-name`).
- Follow the existing code structure and patterns.
- Test your changes thoroughly.
- Submit a pull request using the [PULL_REQUEST_TEMPLATE.md](https://github.com/voxdroid/VoxSpace/blob/main/.github/PULL_REQUEST_TEMPLATE.md).
- Ensure your code adheres to the project's style guidelines.

### 3. Code Style
- Follow TypeScript/JavaScript best practices.
- Use clear, descriptive variable and function names.
- Ensure compatibility with modern browsers and Node.js versions.
- Include dependencies in `package.json` and update documentation accordingly.

### 4. Testing
- Test your changes in a development environment.
- Include any setup instructions in the documentation.
- Ensure the application builds and runs without errors.

### 5. Documentation
- Update relevant documentation files with clear explanations.
- Suggest improvements to the main `README.md` or other documentation files if needed.

## Getting Help
If you need assistance, refer to [SUPPORT.md](SUPPORT.md) or open an issue with the “question” label.

## Code of Conduct
All contributors must adhere to our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Thank you for helping make **VoxSpace** better!
